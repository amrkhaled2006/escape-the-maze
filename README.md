# Escape the Maze

A simple 2D console game built in C++. Move the player through the maze, avoid the traps and reach the exit before running out of stamina

## Game Rules
--> Reach the exit ('E') starting form ('p')
--> You have **30 moves** max
--> You have **3 lives**. stepping on a trap ('X') costs 1 life

## Controls
--> 'W' / 'w': Move up
--> 'S' / 's': Move Down
--> 'A' / 'a': Move Left
--> 'D' / 'd': Move Right
--> 'U' / 'u': Undo last step
--> 'Q' / 'q': Quit game

## Map Legend
--> 'p': Player
--> '#': Wall
--> '.': Path
--> 'X': Trap
--> 'E': Exit

## Built With
--> **Languages:** C++ Basics
--> **Data Structures:** 2D Vector, Stack
